## Overview

**SpellBook of Skill** is your go-to resource for **structured, practical developer guides** designed to save you time and accelerate your learning. Whether you're a beginner learning the basics or an experienced developer exploring new technologies, you'll find carefully curated tutorials organized by topic and difficulty.

### What You'll Find Here

- **Structured Guides**: step-by-step tutorials with clear learning objectives
- **Practical Examples**: each guide includes working code and real-world scenarios
- **Easy to Follow**: progressive complexity from fundamentals to advanced topics
- **Language & Framework Agnostic**: core concepts that transfer across technologies
- **Comprehensive Documentation**: prerequisites, exercises, and troubleshooting included

## Key Features

- **Organized by Category**: guides sorted by topic and skill level
- **Live Documentation**: hosted on Astro with Starlight for fast browsing
- **Community-Driven**: open-source with contribution guidelines
- **Project-Based Learning**: build real projects as you learn
- **Practical Focus**: learn skills you can apply immediately

## Quick Start

### 1. **Browse the Documentation**

Visit the [live documentation site](https://spellbook-of-skill.netlify.app) to explore all available guides.

Or clone and run locally:

```bash
git clone https://github.com/DomeT99/spellbook-of-skill.git
cd spellbook-of-skill
pnpm install
pnpm dev
```

Open [http://localhost:4321](http://localhost:4321) in your browser.

### 2. **Pick a Guide**

Find a skill that matches your learning goals and work through it step by step.

### 3. **Follow Along**

Complete the exercises and build the project as you go. Don't just read — code along.

### 4. **Apply & Share**

Adapt what you've learned to your own projects. Share your results with the community.

## Contributing

We welcome contributions, whether you want to add a new guide, improve an existing one, or fix a bug.

For the full contribution guide, see [CONTRIBUTING.md](CONTRIBUTING.md).

### How to Contribute

1. **Search existing guides** to avoid duplicates.
2. **Add or update a guide** in the appropriate category folder.
3. **Include essential documentation** with a clear title, description, and example.
4. **Open a pull request** with a short summary of your changes.

### Contribution Guidelines

- Keep guides **concise and actionable**.
- Provide at least one **complete code example**.
- Include **prerequisites** and **learning objectives**.
- Add a **troubleshooting section** for common issues.
- Never include **real secrets or sensitive data**.

## Installation & Setup

### Prerequisites

- Node.js 18+
- pnpm

### Development

```bash
# Clone the repository
git clone https://github.com/DomeT99/spellbook-of-skill.git
cd spellbook-of-skill

# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build

# Preview production build
pnpm preview
```

### Scripts

```bash
pnpm dev      # Start local dev server
pnpm start    # Alias for dev
pnpm build    # Build for production
pnpm preview  # Preview production build
pnpm astro    # Direct Astro CLI access
```
