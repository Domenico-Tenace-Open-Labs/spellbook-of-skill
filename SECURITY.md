# Security Policy

Thanks for helping keep SpellBook of Skill safe. This is a static documentation site, but we still take coordinated disclosure seriously. If you found a vulnerability or a security-relevant misconfiguration in this repository, please report it privately.

## Reporting a Vulnerability

Do not open a public issue for a suspected security problem. Instead, report it directly via GitHub private vulnerability reporting.

**How to report:**

1. Open the repository on GitHub: https://github.com/DomeT99/spellbook-of-skill
2. Go to **Security** → **Report a vulnerability** (GitHub private vulnerability reporting).
3. Include in your report:
   - the affected file and line, when known;
   - a short description of the issue;
   - steps to reproduce, if applicable;
   - severity assessment, if you have one.

Alternatively, email the maintainer directly (see the repository profile on GitHub).

## What to expect

- Acknowledge receipt of your report within 5 business days.
- We will work on a fix and keep you informed of progress.
- Once resolved, we are happy to credit you if you wish.

## Scope

This repo contains only the documentation source and static build configuration for the site. It includes no application backend, user authentication, or server-side data handling. We appreciate reports regardless, since misconfigurations here can still affect the deployed site (for example wrong canonical URLs, sitemap, or metadata).
